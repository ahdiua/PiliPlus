# CDN 优选、播放缓冲与 BTR

本分支保留现有 media_kit/mpv 播放器，增加三层网络优化。设置入口为
「设置 → 音视频设置」；播放页「更多」也可以直接切换 BTR。

## 使用与设置记忆

- **单 CDN 直连**：默认继续使用原来保存的 CDN。原 `CDNService` 和
  「音频不跟随 CDN 设置」保持独立，不会被测速或 BTR 自动写入。
- **直连 CDN 自动优选**：默认关闭。开启后，对当前视频最多四个不同节点探测，
  同时最多两个请求，每个最多 128 KiB，整次最多等待 1.2 秒。
  选择一个有效节点交给播放器直连；失败时使用原来保存的地址。
  结果按资源/候选缓存两分钟，最多 64 项；刷新签名时使用新的 URL，网络变化时清空。
  这是短样本优选，不能保证长期吞吐，也不会让直连播放变成并发下载。
- **按码率自动扩展缓冲**：默认开启。根据所选音视频总码率、倍速、缓冲时长
  计算前向缓存，留 20% 余量，自动目标最高 64 MiB。手动缓冲大小作为下限，
  后向缓存仍使用手动大小；用户手动设得更大时保留该值。
  无码率信息时自动目标为 16 MiB。关闭后恢复原有缓冲大小，直播不受影响。
- **BTR 多线程加速**：默认关闭。开启后音视频共用连接预算，自动选择并发
  CDN，按速度分配分块、补救慢请求，并严格校验 Range 响应与资源长度。
  海外节点默认开启，也可改用大陆节点。自动并发默认开启，起播最高先到 16，
  后续在 8/12/16/24/32/48/64 档调整；手动模式可选 4/8/16/32/64，默认 8。

**关闭 BTR 会立即取消其下载会话并关闭本地监听，在当前进度重新打开直连播放源，
保留原来的播放/暂停状态。** 原来保存的单 CDN 地址、音频 CDN 规则和直连自动优选
开关均保留；若直连自动优选关闭，则恢复保存的单 CDN；若用户单独开启过优选，
则回到优选一个节点进行直连的模式。

画质切换、换视频、拖到缓存外和退出时会取消不再需要的请求。
暂停和后台播放由播放器原有缓存读取行为控制，不在缓存已满足时主动下载整个文件。
本地 HTTP 服务仅监听 `127.0.0.1` 随机端口，路径含随机会话标识。

## 覆盖范围

普通 DASH 视频及符合条件的番剧/电影等剧集。剧集可单独关闭加速；标有 DRM
或试看标记的剧集保持直连。本地文件、直播、非 DASH 视频和离线下载保持现有路径。
手动输入的播放 URL 不会因候选地址存在而被自动替换。
代理启动失败回到手动直连；播放期间下载错误交给现有播放器重试逻辑处理。

## 测试

Flutter 环境可运行：

```text
flutter test test/thread_ripper_test.dart test/thread_ripper_auto_test.dart test/playback_network_test.dart test/playback_metadata_test.dart
```

只有 Dart SDK 时，可在 Windows 运行：

```powershell
./tool/test_network_core.ps1 -Dart '路径/dart.exe'
```

脚本在 Git 忽略的 `.fvm/network-core-tests` 中复制实际网络核心，仅替换测试框架
import，然后运行静态检查与原有断言。不会包含依赖 Flutter 的剧集元数据测试。
测试以本地模拟 CDN 验证 Range 字节一致性、错误响应、续传、连接预算、拖动取消、
开关恢复、优选期限与缓存。通过这些测试不代表已在真机完成性能、耗电或后台播放验证。
